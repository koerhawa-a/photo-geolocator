A model-free street-photo geolocator: it decodes each photo's JPEG with its own pure-Python baseline decoder, answers the geometric median of the public practice pool by default, and moves the answer to the Americas' median when the photo shows a strong yellow road marking.

## Run it

```sh
python3 -P -s main.py
```
